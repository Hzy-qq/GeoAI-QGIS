# 运行目录说明

当前项目有两层：

```text
qgis-geoagent/          # 项目总目录
  requirements-advanced.txt
  GeoAI/                # 增强版 GeoAI 项目目录
    requirements-advanced.txt
    scripts/
    geoai_agent/
```

如果终端当前在项目总目录：

```powershell
F:\研一\GitHub项目\qgis-geoagent
```

可以这样安装依赖：

```powershell
pip install -r requirements-advanced.txt
```

运行 GeoAI 增强版脚本时，需要写完整子路径：

```powershell
python GeoAI/scripts/check_llm_config.py
python GeoAI/scripts/build_chroma_store.py
python GeoAI/scripts/retrieve_chroma_knowledge.py "计算点要素周围1公里范围内的道路长度"
python GeoAI/scripts/evaluate_chroma_rag_planner.py
python GeoAI/scripts/run_langgraph_chroma_task.py "统计 places 周边 700 米范围内道路的长度"
```

如果终端当前在 GeoAI 子目录：

```powershell
F:\研一\GitHub项目\qgis-geoagent\GeoAI
```

则运行：

```powershell
pip install -r requirements-advanced.txt
python scripts/check_llm_config.py
python scripts/build_chroma_store.py
python scripts/retrieve_chroma_knowledge.py "计算点要素周围1公里范围内的道路长度"
python scripts/evaluate_chroma_rag_planner.py
python scripts/run_langgraph_chroma_task.py "统计 places 周边 700 米范围内道路的长度"
```

建议在 PyCharm 中把工作目录设为 `GeoAI`，这样运行脚本路径更短，也更符合当前增强版项目结构。
